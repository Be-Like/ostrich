# Context

This folder contains a hierarchy of various context documents.

## Design

Read the `repo_root/context/design.md` file to gain an understanding of the
design goals of the project.

## Workflow

Read the `repo_root/context/workflow.md` file to understand how a user
interfaces with ostrich — the happy-path interaction flows and the
high-level UI layout. It sits beneath `design.md` and above the
per-project documents under `context/projects/`.

## Theme

Read the `repo_root/context/theme.md` file for ostrich's look, feel,
and voice — the dark cyberpunk multi-neon visual identity, typography,
motion/FX, and the full-camp infiltration/heist copy. It is a peer to
`workflow.md` (workflow owns *what panels exist and how you move
through them*; theme owns *how they look and what they say*) and is
sovereign over wording and look only — never structure or
architecture.
