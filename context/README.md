# Context

This folder contains a hierarchy of various context documents.

## Design

Read the `repo_root/context/design.md` file to gain an understanding of the
design goals of the project.

## Workflow

Read the `repo_root/context/workflow.md` file to understand how a user
interfaces with ostrich — the happy-path interaction flows and the
high-level UI layout. It sits beneath `design.md` and above the
per-project documents under `context/projects/`.
